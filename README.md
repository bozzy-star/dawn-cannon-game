# 弩級戦艦 朝日

スマホ・PCのブラウザで遊ぶ、1門から最大4門へ増設する主砲と、自動対空・対潜兵装、任意の航空戦艦改装による海域制圧ゲームです。全5部・35海域の架空世界を進み、獲得資金で各門の兵装を強化し、弾薬・燃料の補給と船体の修理を行います。自動対空迎撃、戦闘画面内のソナー・対潜操作、個別の主砲強化、艦種別の撃沈報告と発射号令、参考画像を意識した艦体・海・主砲の外観を備えています。新しく始める朝日は通常戦艦・主砲1門です。第一部で各兵装を強化してから、伊勢を意識した航空戦艦へ任意で改装し、迎撃機・爆撃機・戦闘機を編成・更新できます。

v9.2は速度切り替え・空襲と回避・各部の拡大地図も調整しています。開始時の絵も一門の通常戦艦に揃え、実際の3D艦体へ鋼板と木甲板の画像素材を貼っています。多段艦橋・窓枠・艤装・喫水線・格納庫を改良し、主砲機構・給弾・装甲の強化も艦の外観に反映します。装飾だけの無料主砲はありません。画像素材を読み込めない場合も、標準の材質でゲームを続けられます。

## はじめに

1. スマホは横向き推奨。保存済みの航海は続きから遊べます。「新しい航海（通常戦艦・主砲1門）」で始めると、前の航海を履歴に残してから初期状態に切り替えます。「作戦地図」から第1海域を選んで出撃します。
2. 海面をドラッグして照準し、右下の「発射」を押します。長押しで装填後も連続発射。「斉射」は装填済みの砲身を同時に発射します。動く敵には、着弾までに進む位置を見越して狙ってください。
3. 新規開始は飛行甲板・航空隊のない通常戦艦で、主砲は1門です。港で最大4門へ増設できます。装備中の砲身は同じ砲塔で一緒に旋回・上下し、それぞれ別に装填します。通常射撃は第1門から順に発射し、左下の01〜04で次に撃つ門を選べます。
4. 各海域の2波を撃破すると制圧。上陸支援作戦では、その後の陸上目標も鎮圧します。勝利後は8秒間、上空から朝日を回り込んで船体と損傷を確認し、撃沈数、航空撃墜数、得点、命中率、耐久、所要時間に応じた報酬を受け取ります。
5. 港の「強化パーツ」と「消耗品・補給」で次の敵に備え、損傷は有料修理で直します。必要兵装や最低補給量が足りない作戦には出撃できません。制圧済み海域にも再出撃できます。
6. 通常戦艦で第一部の6海域を制圧し、第7海域を解放すると、任意で航空戦艦へ改装できます。改装後も主砲と既存兵装は残り、通常戦艦と航空戦艦を港で無料切り替えできます。

音は最初のボタン操作で有効になります。右上の「音 ON / OFF」で切り替えられます。

敵は駆逐艦、巡洋艦、戦艦、3種類の空母、潜水艦、突撃艦です。突撃艦は第4海域から登場し、砲撃よりも接触を狙います。衝突は最大船体耐久の80%の損害になるため、警告が出たら優先砲撃か操艦・回避で進路を外してください。空母の搭載枠は9機・15機・30機の3種類です。実際に送り出す編隊の機数、同時に出る敵機の上限、次の発艦までの間隔は、海域の部と出撃時の対空装備に合わせて調整します。潜水艦は未探知なら遠方に表示されず、近距離の薄い船影や魚雷の航跡が手掛かりになります。主砲や龍神砲では潜水艦を撃沈できません。

敵艦は朝日を航過すると、そのまま止まらずに旋回して再攻撃します。並走や交差ではお互いの速度差と進行方向を見て偏差射撃し、近づいた敵には操艦や回避で距離を取ってください。

**最初の3海域は購入不要の教習です。** 第1海域で照準と偏差射撃、第2海域で龍神砲の発射タイミング、第3海域でソナーと爆雷の操作を覚えます。第1海域は初期の主砲弾と燃料を使います。第2・第3海域で必要になる教習用の兵装・弾・燃料は、その出撃だけ貸与されます。購入済みの装備や在庫を上書きせず、教習終了後に恒久パーツや補給品として残りません。

**第2海域「南天列島防衛戦」は60機ずつ2波、計120機の爆撃機が来襲します。** 龍神砲・蓄電槽と訓練弾2発分、高角砲を貸与します。各波の開始約2.5秒後に「今だ！」の合図が出て、発射の練習中は時間が止まります。光る龍神砲ボタンを押し、第2波にも残る1回を使ってください。出撃前に高額パーツや龍神弾を購入する必要はありません。

第3海域「青蓮島沖海戦」では、貸与アクティブソナーをONにして潜水艦を探知します。教習の潜水艦は最初から爆雷の射程内にいます。時間が止まる操作案内に従って接触を選び、探知した深度50 mと位置へ貸与爆雷を投下してください。通常作戦の爆雷投下は1200 m以内です。潜水艦は通常主砲や龍神砲で倒せません。

通常作戦の恒久対空装備は高角砲（第2海域・600 C）→対空機関砲（第5海域・追加1800 C）→特殊対空弾（第11海域・追加3200 C）の順に準備します。第2の龍神砲教習を除く通常作戦は、装備に合った少数編隊の迎撃から始まり、部が進むほど同時上限が増えます。最終レーダーを揃えると、強化された自動迎撃で大きな編隊に対応できます。通常作戦の空襲は対空装備に合わせて少し増やし、投下された爆弾の着弾予測を表示します。着弾約0.6秒前に左右旋回ボタンが光ったら回避の合図です。各作戦の「対空装備目安」と、現在の装備に合わせた出現機数を港で確認してください。

## 航空戦艦への改装と航空隊

序盤は通常戦艦の主砲1門で始め、報酬から主砲の増設・個別強化、自動対空、レーダー、対潜兵装を整えます。第一部の6海域を制圧して第7海域を解放すると、1800 Cで航空戦艦改装を購入できます。主砲4門までの構成と各門の強化、対空・対潜・レーダー、船体装甲などを保持したまま、飛行甲板と初期航空隊6機を追加します。改装時に航空弾150単位を一度だけ受領します。新規開始時には飛行甲板も航空隊もありません。改装は任意なので、通常戦艦のまま35海域を進むこともできます。

改装後は「通常戦艦」と「航空戦艦」を無料で切り替えられます。通常戦艦では航空隊の発艦を停止し、航空隊の購入・強化・配分は保持します。航空戦艦では主砲を撃ちながら、搭載した航空隊が自動で発艦・攻撃・帰艦・再整備します。

| 航空隊 | 主な役割 | 基本の配分 |
| --- | --- | --- |
| 迎撃機「蒼衛」 | 接近する敵機を優先して迎撃。水上艦・陸上施設は攻撃しません。 | 2機 |
| 爆撃機「白槍」 | 水上艦・陸上施設への打撃。敵機と戦わないため護衛が必要です。 | 2機 |
| 戦闘機「天環」 | 爆撃機の護衛と敵機の掃討。敵機がいなければ水上・陸上にも限定攻撃します。 | 2機 |

各機種は0以上の整数で割り当て、合計を搭載容量以内にします。均等配分では搭載枠を3機種へ同数ずつ割り当てます。格納庫は6機から、12・24・36・60機へ拡張できます。増えた枠は配分を変更して使用してください。

各機種の性能は個別に、レシプロ → 初期ジェット → 超音速 → 第四世代 → 先進ステルス → 第五世代ステルスの6段階へ進みます。更新は第7・13・19・25・31海域で解放され、各機種ごとに500・1000・2200・3600・5400 Cです。速度・火力・耐久・航続範囲と再整備時間が改善します。最終機は架空世界内での最高段階であり、現実の航空機との優劣比較ではありません。

航空攻撃1回は航空弾5単位、1機の発艦は燃料15単位を使います。航空隊を多く積むと消費も増えるため、修理・主砲弾・対空弾などに加えて、航空弾と燃料を準備してください。航空弾が不足すると航空攻撃が停止します。燃料切れによる撤退は通常戦艦と共通です。

## 航行・天候・上陸支援

正面から近づく敵だけでなく、並走する艦隊や航路を横切る敵も現れます。砲弾が届くまで敵は動き、風で弾道もずれます。遠方では敵の進行方向へ照準を先行させる偏差射撃が必要です。射撃管制は速度と風の補正を助けます。

海域ごとに朝・昼・夜、晴れ・曇り・雨・嵐、風と波を設定しています。雨と嵐ではレーダー範囲が0.7倍になり、波や砲撃・被弾で船体が揺れます。海峡や運河は両岸の砲台に注意してください。岸砲台は航行開始後に砲撃を始め、狭い海域では左右への回避幅も小さくなります。

全35海域のうち12海域に上陸支援があります。朝日は海岸手前で減速して砲撃支援を行い、海上戦の後、岸の砲台、移動する戦車、航空隊を出す飛行場を鎮圧します。上陸支援開始から味方が着岸するまでの期限は第一部118秒から最終部70秒へ短くなり、陸上目標も増えます。

揚陸艇は期限の6秒前に出港し、期限に着岸します。先に岸目標・航空機・機雷をすべて排除した場合は上陸を前倒しし、出港から6秒で着岸して勝利します。期限を迎えても敵が残っていると、岸からの砲撃と空襲で上陸部隊が損耗し、部隊が壊滅すると作戦失敗になります。機雷を避けながら戦うため、燃料と弾薬に余裕を持たせてください。

## 補給と撤退

主砲弾・対空弾・対潜弾・龍神弾・燃料は消耗品です。表示は「単位」で、主砲1門の射撃は5単位、斉射は実際に撃った門数×5単位（最大4門なら20単位）、対空・対潜・龍神砲は1射につき各5単位を使います。巡航の燃料消費は毎秒5、低速は2秒ごとに5、全速は毎秒10です。

| 補給品 | 1パックの量 | 価格 |
| --- | --- | --- |
| 主砲弾 | 150単位 | 240 C |
| 対空弾 | 300単位 | 260 C |
| 対潜弾 | 30単位 | 450 C |
| 龍神弾 | 5単位 | 550 C |
| 燃料 | 600 | 180 C |
| 航空弾 | 150単位 | 240 C |

燃料は燃料庫の容量まで積載できます。1パックが入りきらない場合は、入る分だけ購入し、価格も比例して減ります。戦闘に必要な弾薬や燃料が尽きると撤退します。発射済みの攻撃は結果を待って判定します。再出撃しても在庫は元に戻らないため、港で残量を確認してください。敗北・撤退の報酬は0です。

新規開始時は資金1200 C、主砲弾180単位、対空弾240単位、対潜弾30単位、燃料900。第2・第3教習では貸与した訓練弾と燃料で出撃でき、第1教習と通常作戦の出撃には主砲弾30単位・燃料100以上が必要で、航空隊のある作戦では対空弾100単位、潜水艦のある作戦では対潜弾15単位も必要です。この最低量だけで勝てるとは限りません。

船体と艦首・艦尾・左舷・右舷・艦橋・機関部の損傷は帰港後も残ります。港の有料修理で全体と各部位を直せます。船体状態35%未満では出撃できません。

資金不足で再出撃できない場合は、「消耗品・補給」の緊急復帰を利用できます。**通常の修理と第1海域再挑戦用の補給を払えない場合だけ**使えます。船体を65%以上、各部位の損傷を35以下、主砲弾を150単位、燃料を900の最低量まで戻し、第1海域で資金を立て直せます。対空弾・対潜弾・龍神弾と資金は増えません。

## 作戦地図と保存

舞台は太平洋に似た位置関係を持つ架空の地球です。暁和国、黎明合衆国、チーナ帝国、南天諸邦の架空の国と、海域・都市を使います。南天・珊瑚洋への反攻、母港への帰還、北海の迂回、黎明合衆国への遠征をたどる5部・35海域を収録しています。制圧した海域は地図上の管理圏として塗られ、部が進むほど敵艦の耐久・攻撃も強くなります。

地図は全体表示と各部の拡大表示を切り替えられます。拡大表示では選択した部の作戦地点・航路・制圧圏だけを表示します。第1部の拡大には第1部の6海域だけが表示され、全体マップでは全35海域を確認できます。港では作戦に必須のパーツと推奨パーツを色で区別し、必要な装備と補給を確認できます。主砲と主砲機構の必要条件は同じ1門に揃えればよく、全門の強化は不要です。増設する前に、必須装備・補給・修理の資金を確保してください。

制圧状況、資金、装備、消耗品、戦績、船体状態、部位損傷、航空戦艦改装・船体形式・機体の世代・航空隊配分はこのブラウザに保存されます。スマホとPCでは自動共有されません。前版の進行は引き継ぎ、旧在庫は5倍の単位へ一度だけ換算します。v5以前に装備していた3門は維持され、以前の主砲・出力・給弾の段階をその3門に引き継ぎます。新規開始だけが1門になります。航空改装の前版からも、既存の主砲構成と兵装・資金・在庫・進行を保持して移行し、未購入の航空改装や航空弾を勝手に追加しません。前版の第3〜6海域で既に購入した航空改装も、航空隊・船体形式・在庫とともに保持します。新しい第7海域条件は、これから改装を購入する場合に適用します。新しい航海を始める前には、現在の進行を別の航海履歴へ保存します。過去の航海へ復帰する場合も、切り替え前の航海を履歴に残すため、元の航海へ戻れます。履歴の保存に失敗したときは切り替えず、現在の進行を保ちます。履歴は自動で削除しません。保存を利用できない環境では、開いている間だけ進行と航海履歴を保持します。「進行をリセット」は確認画面で削除を選ぶと実行されます。

通常砲撃の命中率は、命中数 ÷ 発射した砲身数です。龍神砲や航空機撃墜は通常砲撃の命中率に含めません。

## 音と検証

若い男性が海上で感情的に叫ぶ掛け声を意識した合成音声を同梱しています。「敵、駆逐艦、撃沈！」などの艦種別報告、「撃てえーッ！」「全砲門！ 撃てえーッ！」の発射号令、「敵機発見！ 来るぞッ！」と、艦首・艦尾・左舷・右舷・艦橋・機関部の「被弾！ 被弾だッ！」報告があります。声優による録音ではありません。報告が重なる場合は被弾を優先し、同じ掛け声の連呼を抑えます。

低い爆発、破片、艦体の軋み、着水音を重ねた効果音、SUNKのモールス信号、ソナーの探信音も実装しています。音声素材を読み込みできない場合は端末の読み上げ機能を利用し、声質は環境によって変わります。

ゲーム処理はThree.jsの座標・形状計算を使うシミュレーションで検証しています。音声素材の波形と読み込み・再生制御も検証しています。スマホ実機での音声の聞こえ方は未確認です。タッチ操作感、動作負荷も実機での確認が必要です。

## ローカル起動

ゲームのフォルダで `python3 -m http.server 8094` を実行し、ブラウザで `http://localhost:8094` を開きます。JavaScriptのモジュールを使うため、`index.html` の直接ダブルクリックには対応していません。

Three.js r180を同梱しています。ライセンスは `vendor/THREE-LICENSE.txt` を参照してください。

世界設定・各部の物語・35作戦の一覧は [世界設定と兵装仕様](WORLD.md) を参照してください。

港の「船体を見る」では、修理前・修理後の朝日を上空から確認できます。制圧時・港の船体確認は8秒で一周し、ボタンで戦績または港へ戻れます。
