# 弩級戦艦 朝日

スマホ・PCのブラウザで遊ぶ、3門の大砲による海域制圧ゲームです。

**ゲームURL：https://bozzy-star.github.io/dawn-cannon-game/**

## 遊び方

1. スマホを横向きにし、海域を選んで出撃します。
2. 海面をドラッグして照準。左下の01〜03で主砲を選び、右下の「発射」を押します。長押しで自動装填後も発射できます。
3. 「斉射」は装填済みの大砲をまとめて発射します。
4. 2波の敵艦を倒すと海域制圧。撃沈数・得点・命中率・耐久・所要時間を確認し、獲得資金で港のパーツを購入します。
5. 次の海域へ進み、主砲を通常弾 → 徹甲弾 → 炸裂弾 → 電磁砲 → 光子主砲へ進化させます。
6. 第5海域の解放後は「龍神砲」を購入できます。3門が合体し、現在出現しているすべての敵艦を撃沈します。1海域への出撃につき1回で、次の増援では回復しません。再出撃すると回復します。

PC：ドラッグ / 矢印キーで照準、Spaceで発射、Fで斉射、Gで龍神砲、1〜3で砲を選択。Escで一時停止。

## 作戦海域

| 海域 | 作戦名 | 主な敵 |
| --- | --- | --- |
| 1 | 霧の入口 | 駆逐艦のみ |
| 2 | 鋼鉄の回廊 | 駆逐艦・巡洋艦 |
| 3 | 巨艦の砦 | 巡洋艦・戦艦 |
| 4 | 翼の群島 | 空母と護衛艦 |
| 5 | 黒潮決戦域 | 全艦種の混成 |
| 6 | 夜明けの中枢 | 主力艦隊の最終決戦 |

各海域には作戦説明と2波の艦隊があります。制圧済みの海域へ再出撃し、追加資金を獲得することもできます。港では主砲、装填装置、追加装甲、龍神砲を購入できます。

## 戦績と進行保存

- 命中率：命中した通常砲撃数 ÷ 発射した通常砲撃数。斉射は発射した砲門ごとに数えます。
- 龍神砲の撃沈は撃沈数と撃沈点に加算し、通常砲撃の命中率には含めません。
- 撃沈点、命中率、耐久、時間から総合得点と報酬を算定します。
- 勝利で次の海域を解放。敗北時の報酬は0です。
- 制圧状況・資金・装備・自己ベストは、このブラウザのローカル保存に記録します。スマホとPCで自動共有はしません。
- 保存機能が利用できない環境では、開いている間の進行のみ保持します。
- 港の「進行をリセット」は確認画面から削除を選ぶまで実行しません。

## 音と演出

重い砲声、金属の命中音、着水の水柱と落下水滴音、艦体の軋みを伴う沈没音、SUNKのモールス信号、日本語の「敵艦、沈没。」音声、エネルギー主砲と龍神砲の音を実装しています。音源はコードで合成し、日本語音声は端末の読み上げ機能を利用します。音声の有無・声質は端末によって変わります。音を切る場合は右上の「音 ON」を押してください。

敵艦は駆逐艦・巡洋艦・戦艦・空母で形状が異なります。空母の航空機はこの版では甲板上の表示です。

## ローカル起動

このフォルダで `python3 -m http.server 8094` を実行し、ブラウザで http://localhost:8094 を開きます。JavaScriptのモジュールを使うため、index.htmlを直接ダブルクリックする方法には対応しません。

Three.js r180を同梱しています。ライセンスは vendor/THREE-LICENSE.txt を参照してください。
