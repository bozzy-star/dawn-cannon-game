# スマホ版 弩級戦艦DAWN

## 遊び方

スマホでゲームのURLを開き、横向きにして「タップして出撃」を押します。

1. 海面をドラッグして敵艦へ照準を合わせます。
2. 左下の01・02・03で大砲を選び、右下の「発射」を押します。長押しも可能です。
3. 「斉射」で装填済みの大砲をまとめて撃ちます。
4. 3波の敵艦隊を撃退するとクリア。艦体耐久が0になると終了です。

発射後は各砲が約2.7秒で自動装填されます。照準が敵艦へ近づくと補助照準が働きます。敵艦の赤茶色の機関部に直撃すると大きなダメージを与えます。

PCではドラッグまたは矢印キーで照準、Spaceで発射、Fで斉射、1〜3で大砲を選択できます。右上から音のオン・オフ、一時停止ができます。

## ローカル起動

このフォルダで `python3 -m http.server 8094` を実行し、ブラウザで http://localhost:8094 を開きます。

## 実装

Three.js r180による3D表示。波・空・鋼鉄の質感、3門の独立装填、斉射、弾道と着弾、敵艦隊3波、艦体耐久、発射の反動と煙、Web Audioで合成する重低音の砲声。外部の音声・画像ファイル不要。

Three.jsのライセンスは vendor/THREE-LICENSE.txt を参照してください。

## 検証

ゲーム処理のシミュレーションで、3門の独立装填・弾道の命中・斉射・一時停止・3波クリア・再出撃時のメモリ解放を確認しました。ブラウザ操作の承認が拒否されたため、実際の表示・スマホ実機の操作・音の聴感は未確認です。
