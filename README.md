# 弩級戦艦 朝日

スマホ・PCのブラウザで遊ぶ、三連装主砲と対空・対潜兵装による海域制圧ゲームです。全5部・35海域の架空世界を進み、獲得資金で兵装を強化し、弾薬と燃料を補給します。

**[公開ゲームを遊ぶ](https://bozzy-star.github.io/dawn-cannon-game/)**

## はじめに

1. スマホは横向き推奨。「作戦地図」から第1海域を選んで出撃します。
2. 海面をドラッグして照準し、右下の「発射」を押します。長押しで装填後も連続発射。「斉射」は装填済みの砲身を順に発射します。
3. 主砲は一基の三連装砲塔です。3本の砲身が一緒に旋回・上下し、それぞれ別に装填します。左下の01〜03で発射する砲身を選べます。
4. 各海域の2波を撃破すると制圧。撃沈数、航空撃墜数、得点、命中率、耐久、所要時間に応じた報酬を受け取り、次の航路を開きます。
5. 港の「強化パーツ」と「消耗品・補給」で次の敵に備えます。必要兵装や最低補給量が足りない作戦には出撃できません。制圧済み海域にも再出撃できます。

音は最初のボタン操作で有効になります。右上の「音 ON / OFF」で切り替えられます。

| 操作 | スマホ・画面ボタン | PC |

| 照準 | 海面をドラッグ | ドラッグ、矢印キー、W/A/S/D |
| 主砲発射 / 砲身選択 | 発射を長押し / 01〜03 | Space / 1〜3 |
| 斉射 / 龍神砲 | 斉射 / 龍神砲 | F / G |
| ソナー切替 | ソナー ON / OFF | V |
| 対潜発射 / 接触選択 | 対潜兵器 / 潜水接触を選ぶ | H / R |

| 一時停止 | 右上の一時停止 | Esc |

対潜装備を購入すると操作ボタンが現れます。爆雷は海面の照準位置へ投下し、深度を指定します。魚雷・アスロックは探知した潜水接触を選んで発射できます。

## 兵装と敵への備え

| 強化系統 | 強化の流れ・効果 |
| --- | --- |
| 主砲 | 通常砲弾 → 徹甲弾 → 炸裂弾 → 電磁砲 → 光子主砲。装填装置と装甲も強化できます。 |
| 龍神砲 | 出現中の水上艦と航空機を一掃。初期装備では1出撃1回、蓄電槽で2回まで。1回につき龍神弾1個が必要で、潜水艦には効きません。 |
| 対空 | 中・長距離の高角砲 → 近距離の対空機関砲を追加 → 特殊対空弾。射程内の爆撃機を対空弾を消費して自動迎撃します。 |
| レーダー | 遠距離 → 広域 → 射撃管制・VT信管。索敵・砲撃距離を延ばし、最終段階では航空機の近くで対空弾が起爆します。 |
| ソナー | パッシブ → アクティブ → ソノブイ哨戒機。パッシブON中は主砲の装填時間が2倍。アクティブは2000m以内を探知し、接近すると探信音が速くなります。ソノブイは哨戒機と投下演出の後、全距離の潜水艦を探知します。 |
| 対潜 | 爆雷 → 直進対潜魚雷 → 誘導対潜魚雷 → アスロック。爆雷は数秒後に爆発し、位置・深度のずれで威力が減ります。誘導兵器には探知した目標が必要です。 |

敵は駆逐艦、巡洋艦、戦艦、3種類の空母、潜水艦です。空母は3機・5機・10機ずつ爆撃機を発艦させます。潜水艦は未探知なら遠方に表示されず、近距離の薄い船影や魚雷の航跡が手掛かりになります。

**第2海域「南天列島防衛戦」では60機ずつ2波、計120機が来襲します。** 高角砲・龍神砲・蓄電槽と龍神弾2個を準備し、各波で龍神砲を1回ずつ使ってください。この作戦の勝利には龍神砲2回の使用が必要です。

## 補給と撤退

主砲弾・対空弾・対潜弾・龍神弾・燃料は消耗品です。戦闘に必要な弾薬や燃料が尽きると撤退します。再出撃しても在庫は元に戻らないため、港で残量を確認してください。敗北・撤退の報酬は0です。

資金不足で再出撃できない場合は、「消耗品・補給」の緊急補給を利用できます。**主砲弾が6未満または燃料が20未満で、不足を補う通常補給セットの購入資金もない場合だけ**使えます。主砲弾を最低30発、燃料を最低120に補充し、第1海域で資金を立て直せます。対空弾・対潜弾・龍神弾と資金は増えません。

## 作戦地図と保存

舞台は太平洋に似た位置関係を持つ架空の地球です。暁和国から南天・珊瑚洋へ進み、母港への帰還、北海の迂回、環洋連邦への遠征をたどる5部・35海域を収録しています。制圧した海域は地図上の管理圏として塗られ、部が進むほど敵艦の耐久・攻撃も強くなります。

制圧状況、資金、装備、消耗品、戦績はこのブラウザに保存されます。スマホとPCでは自動共有されません。保存を利用できない環境では、開いている間だけ進行を保持します。「進行をリセット」は確認画面で削除を選ぶと実行されます。

通常砲撃の命中率は、命中数 ÷ 発射した砲身数です。龍神砲や航空機撃墜は通常砲撃の命中率に含めません。

## 音と検証

男性の合成音声を加工した「敵艦、撃沈！」の無線ボイスを同梱しています。声優による録音ではありません。低い爆発、破片、艦体の軋み、着水音を重ねた効果音、SUNKのモールス信号、ソナーの探信音も実装しています。読み込みできない場合の音声は端末の読み上げ機能を利用し、声質は環境によって変わります。

ゲーム処理はThree.jsの座標・形状計算を使うシミュレーションで検証しています。スマホ実機での音の聞こえ方、タッチ操作感、動作負荷は別途確認が必要です。

## ローカル起動

このフォルダで `python3 -m http.server 8094` を実行し、ブラウザで `http://localhost:8094` を開きます。JavaScriptのモジュールを使うため、`index.html` の直接ダブルクリックには対応していません。

Three.js r180を同梱しています。ライセンスは `vendor/THREE-LICENSE.txt` を参照してください。
