# 音声素材

日本語男性合成音声 Eddy をもとに、若めの男性が海上で怒鳴るイメージの
短い号令・報告を生成しています。v6では単語を強く区切り、短い息継ぎ、
語尾の強勢、若めのピッチ、声の張りと軽いかすれを追加しました。
波形はピーク0.94以下で、音量を上げるためのデジタルクリッピングを防いでいます。
人間の声優による収録ではありません。実機での聞こえ方は端末・音量で変わります。

元音声: 通常語246、強勢語278 words/min。ゲーム素材: 24 kHz / mono / PCM16。
生成処理・中間音・発話一覧は開発用の `work/audio-v6/` に保存しています。
全15素材の合計サイズは約1.05 MBです。

報告の優先順位は被弾→敵機発見→撃沈→発射号令です。古い報告は順番待ちにせず、
発射号令には共通の4.2秒間隔を設けています。ミュート・一時停止で音声は止まります。
個別素材の読み込みに失敗した場合のみ、端末の日本語読み上げへ切り替えます。

砲撃・爆発・ソナー・モールス信号は `audio.js` の手続き生成音です。
